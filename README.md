## Overview

A Monopoly AI trained by multiple random and pre-built models to output a heuristic evaluation function.

Inspired by tradition chess engines, the AI numericizes monopoly positions

- ⚡ Fast
- 🪴 Expandable
- 🍳 Easy to Export

## Current State ⏱️

**5.9.2026**: Monopoly has been succesfully remade from scratch and is fully manually playable.

**6.9.2026**: Adapting game to be fully automated by randomly choosing out of a decision pool
